# Hi I'm Elias

I build websites for businesses that actually works and gets maintained.
Besides that I like to make unnecessary things just because its fun. A few cron jobs on my Raspberry Pi that commit something trivial every day:

- **[HasTheDayHappened](https://github.com/EtmeTech/HasTheDayHappened)**: reliably confirms every day that the day has in fact happened
- **[HowManyMondaysLeft](https://github.com/EtmeTech/HowManyMondaysLeft)**: counts down how many Mondays are left in the year
  
Neither of them serves any practical purpose but they run reliably every day and thats enough of a win for me.
